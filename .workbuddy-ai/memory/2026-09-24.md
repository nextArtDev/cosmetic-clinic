# 2026-09-24 — /v23: jacques-cie.com port

## What shipped

`app/v23/` — a full port of https://jacques-cie.com/ (a dental + implantology
clinic in Sainte-Foy, Québec) re-authored as the fictional Tehran clinic
«کلینیک دندانپزشکی دکتر پارسا و همکاران». RTL/فارسی. Committed as `4277241`
(feature) + `cf19efc` (docs). Nothing outside `app/v23/`, `public/v23/` and one
`.gitignore` line was touched.

The reference turned out to be a **Vue 3 + Vite SPA on headless Craft CMS**, not
a static site — so the port came out of its own artefacts:

- `dist/assets/app-*.css` + 8 per-component lazy sheets (HeroBase, CardService,
  CardsGrid, CardPortrait, CardHuman, SectionServiceList, BlocksBuilder, index)
- the lazy JS chunks (`BlocksBuilder-*.js` etc.), which hold the *site's* motion
  values — the entry bundle only contains the GSAP/Lenis libraries
- the content tree via `POST /api/arepa/graphql`, which needs
  `Authorization: Bearer <gqlToken>` + `Arepa-Csrf-Token: <csrf>`; without them it
  returns a misleading `403 Schema doesn't have access to the "Français" site`.
  Tokens come from `GET /api/arepa/{get_gql_token,get_csrf_token}`.

Recon scripts live in `.tmp-jacques/` (gitignored, added to `.gitignore`).

## The three bugs worth remembering

1. **Stripping `[data-v-*]` also strips a unit of specificity.** Vue scoped CSS
   gets +1 class from the attribute, which is how `.c-footer__grid[data-v-x]
   {display:grid}` beats the *later* global utility `.l-container{display:block}`.
   Drop the attribute and the utility wins → the footer collapsed from 4 columns
   to 1, every child full width. Fix: emit scoped-origin selectors with the
   wrapper class doubled (`.jc-root.jc-root :global(...)`) and include the tier in
   the dedupe key. Footer went 1577px → 792px (reference: 804px).

2. **Grouping rules by media query destroys the cascade.** `.col-2-md` (768px) and
   `.col-5-xl` (1200px) override the same selector; bucketing into
   `Map<media, rules[]>` reorders them by first-encounter, so the narrower
   breakpoint wins and every grid column is wrong. Walk the source tree in order
   and emit as you go.

3. **The wrapper needs `isolation: isolate`.** The reference paints its background
   on `<body>` (which propagates to the canvas, i.e. painted first), so the hero
   photo at `z-index: -2` shows. Re-homed onto the wrapper — an ordinary in-flow
   box — it paints *after* negative-z descendants and the photo vanishes behind
   the background colour.

Also: the reference's `.c-icon svg * { fill: currentColor }` turns every stroked
icon into a solid blob; the port's outline icons need an explicit `fill: none`.

## Motion values transcribed (from the bundle, not eyeballed)

Lenis `duration:1.2, lerp:.6, easing: min(1, 1.001-2^(-8t))`; hero blur
`blur(10rem)/scale(1.1) → blur(0)/scale(1)` 200ms after mount, 1.6s,
`CustomEase("0.66,0,0.34,1")`; hero overlay by scroll **delta** ±0.004 clamped
[0.1,0.4]; image parallax 130% wrapper / 30-130 travel / `scrub:.8`; banner
`maxX` 60|50|40 and `maxY` -10|-30|-40 at xl|lg|below.

## Left alone deliberately

Sub-routes (services/guides/portraits/contact) are not ported — nav and cards use
in-page anchors. The reference's `.c-overlay` element is omitted (empty,
full-screen, `z-index: 1000`, `pointer-events: auto` — an empty one would swallow
clicks). `lazyloaded`/`lazyloading` classes aren't emitted, so those two
transition variants don't apply.
