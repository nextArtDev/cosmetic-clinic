# 2026-09-16

## /v22 — full Elitestone (elitestone.it) rebuild

The user's first pass at `/v22` was a framer-motion approximation with most of
the reference's motion missing. Rebuilt it from scratch, keeping the Persian
آریاسنگ brand and RTL direction (user confirmed), full-depth rebuild.

### Method

Downloaded the reference's real bundles into `.tmp-elite/` (gitignored):
`home.html`, `dist/css/{main,layout}.min.css`, `dist/js/{main,vendors}.min.js`,
then transcribed the actual animation calls out of the minified JS rather than
guessing. That is where the numbers came from — `delay:.025*i`,
`duration:1.5`, `ease:'expo.out'`, `rotateX:-80/rotateZ:10`, the reel's
`y: innerHeight/1.5`, the preloader's `clipPath` polygon, the cursor's
`1 - Math.pow(.9, .06 * deltaMs)` lerp.

Also lifted the token set straight from `main.min.css`: gold `#e0b16b`, soft
`#f0cf9d`, cream `#ffeccf`, body `#495057`, dark `#1a1a1a`, and the
`cubic-bezier(0.83, 0, 0.17, 1)` easing used on nearly every transition.

### Structure

- `lib/engine.ts` — plugin registration, `splitLines()` (SplitText
  reimplementation), `revealTitle/Excerpt/Separator/Block`, Lenis factory.
- `components/` — Experience (root) + Preloader, Cursor, Navigation, Hero,
  Sections (About/Products/Showrooms/Journal/Contacts/CtaShortcuts), Footer,
  Lightbox, bits.
- Reveals are declarative: `data-es-anim="title|excerpt|separator"` /
  `data-es-reveal`, one `querySelectorAll` pass in `gsap.context`.
- `elitone.global.css` is the only global sheet and holds exactly three rules,
  all gated on `html[data-v22-active]` (attribute set while mounted, stripped
  on unmount). Sibling routes spot-checked at 200.

### Bugs found and fixed

1. **Split-line titles rendered as one line.** Two causes, both real:
   - `.esSplit` / `.esLine` were written as local CSS-Module classes but added
     from JS as literal strings, so they never matched → rows stayed
     `display:inline`. Fixed with `:global()`.
   - `splitLines()` grouped purely by `offsetTop`, so a hero title authored as
     three `\n`-joined lines collapsed to one row whenever the words happened
     to fit. Now honour hard `\n` first (via a width:100% zero-width sentinel
     that flushes `offsetTop`), then fall back to natural wrapping.
2. **Lenis destroy recursion** — `Object.assign(instance, { destroy })` where
   the override called `instance.destroy()` (now the override). Capture the
   original first.
3. **Nested `<a>`** in the showroom list (mailto inside the map link) → React
   hydration failure. Split into sibling links.
4. **`public/v22/img/*.jpg` were HTML error pages**, not images (~12KB each of
   "One moment, please…" challenge markup), so every `<img>` decoded to
   nothing and the hero rendered as a black rectangle. Replaced all 15 with
   real Unsplash photos.

## `next build` hangs in this environment (project-wide, not /v22)

Three attempts, incl. one left 40 min, all die identically: after
`✓ Running next.config.mjs`, the build wipes `.next`, creates `.next/lock`,
then holds at 0% CPU with no output — before compiling any route.

- NOT the safe-delete guard: `CODEBUDDY_SAFE_DELETE_ENABLED=0` makes no
  difference, and `NODE_OPTIONS` only preloads `node-language-shim.cjs`
  (no fs shim injected into node here).
- A concurrent `next start -p 3939` holding `.next` was not the cause either.
- Recovery: kill `next build`/`npx` pids, `rm -rf .next/lock`, `npx next dev`,
  wait ~3 min for first compile → routes back at 200, 0 console errors.
- A stalled build leaves `.next` stripped (`build/ static/ types/` gone),
  which breaks any running `next start`.

Treat `tsc --noEmit` + `eslint` + dev-mode Playwright smoke as the gate.
Also: on Windows here, `wmic` is gone and the PowerShell tool returns no
stdout — write output to a file and Read it, or use node `child_process`.
