## Pitfalls hit (saving for memory)

1. `playwright-core` `page.evaluate(fn, a, b)` is ONE-arg — wrap in
   an object.
2. Next.js dev server returns 403 on `/_next/static/chunks/*.js` when
   the request `Origin` header is `http://127.0.0.1:3000` — it's not
   in `allowedDevOrigins`. Use `localhost:3000` in test URLs.
3. Lenis hijacks `scrollIntoView` and `window.scrollTo` — drive the
   page with `page.mouse.wheel(delta, delta)` toward an ABSOLUTE
   target (computed once from `rect.top + scrollY`), not toward the
   current rect.
4. Framer `whileInView` cannot interpolate `clipPath` strings reliably
   on Chromium; use GSAP `fromTo` for clip reveals (consistent with the
   rest of the route, which is GSAP-driven).
5. `next/image` lazy-load blocks if a fully-clipped ancestor (initial
   `clipPath: inset(100% 0 0 0)`) hides it on first paint — the image
   never requests until the viewport reveal fires, but if the reveal
   is also `whileInView`-clip-based you can deadlock. Eager-load with
   `priority` or use GSAP for the reveal.
6. Custom cursor: NEVER overwrite `className` in a state-applier when
   you also add `is-active`/`is-visible` from other code paths — the
   whole-list write strips every other class. Use `classList.remove`
   the previous state + `classList.add` the new one, guarded by an
   `if (next !== state)`. Symptom: native cursor is hidden
   (`html.v10-cursor-hidden`) and the custom one stays at `opacity:0`
   forever → user has no cursor at all.
7. Also don't gate a custom cursor on `prefers-reduced-motion: reduce`
   — Chrome reports `reduce` whenever Windows "Show animations" is
   off, which silently disables it for a huge chunk of desktop users.
   Honour reduced motion in CSS (kill transitions) instead and keep
   the cursor tracking.

## Pitfalls hit

1. **`useReducedMotion` breaks hydration.** It resolves from
   `matchMedia` during the first client render, so it disagrees with
   the server. Worse, framer bakes `initial` into the SSR `style`
   attribute (62 inline transforms in the prerendered HTML), so even
   `initial={reducedMotion ? false : {...}}` desyncs. Fix: exported
   `useReducedMotionSettled()` in `ui.tsx` using
   `useSyncExternalStore(_, () => true, () => false)` — React is
   required to use `getServerSnapshot` for hydration.
   ***Do NOT use `useEffect(() => setMounted(true), [])`** — the
   repo's `react-hooks/set-state-in-effect` lint rule rejects it.*
2. **A pinned stage's `onPointerDown` + `preventDefault()` silently
   kills descendant button clicks** (it suppresses the compatibility
   `click`). Programmatic `.click()` still worked, which made this
   look like a state bug. Fix: split into `onStagePointerDown` (bails
   via `el.closest('button, a, input, select, textarea, [role=slider]')`)
   and `onHandlePointerDown`.
3. ESLint `react-hooks/refs` forbids reading a ref during render —
   write `aria-valuenow` inside the rAF loop instead.
4. Bash heredocs (`cat >> file <<'EOF'`) choke on Persian text; use
   the Write tool for any file containing Arabic-script content.
5. Lenis fights programmatic scrolling in Playwright — run
   deterministic passes with `reducedMotion: 'reduce'` (Lenis is
   skipped) and use `page.mouse.wheel` for real-motion passes.
6. `npm run build` can fail with
   `[safe-delete][SAFE_DELETE_BULK_CONFIRM_REQUIRED]` when Next purges
   `.next/turbopack` ≥50 files. It's a sandbox guard, not a code
   error: `CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run build`.
